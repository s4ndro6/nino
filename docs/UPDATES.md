# Mises à jour de Nino

Depuis la 0.21, l’édition publique utilise Sparkle pour télécharger une mise à jour, vérifier sa signature et installer l’application avec ton accord. Ouvre **Nino → Rechercher une mise à jour…**, puis confirme le téléchargement et **Installer et relancer**. Le téléchargement manuel du DMG reste disponible.

Une dernière installation manuelle est nécessaire depuis les versions 0.20 et antérieures : elles ne contiennent pas ce moteur. Réinstaller la même ancienne version ne le fait pas apparaître.

Dans Réglages, active éventuellement **Me prévenir des nouvelles versions**. Cette recherche GitHub quotidienne reste facultative ; ni téléchargement ni installation en arrière-plan. Tu peux reporter ou ignorer une proposition. Les requêtes réseau transmettent l’adresse IP au service consulté, aucun contenu personnel de Nino.

La relance est refusée pendant une capture, un import, une transcription, une réponse IA, une vérification de fichiers, une connexion ou une sauvegarde. Le travail est revérifié après la sauvegarde sur disque. Les fichiers personnels restent en dehors de l’application.

Nino reste une alpha non notariée par Apple. La signature des mises à jour n’est pas une notarisation : une demande macOS peut encore apparaître. Ne désactive pas les protections du Mac.

**Plusieurs copies ?** Réglages affiche la version et l’édition, avec **Afficher l’app ouverte dans le Finder**. Une ancienne copie Découverte sur un disque externe peut rester ouverte alors qu’un autre Nino a été téléchargé. Les éditions Découverte/Portable ne sont pas remplacées automatiquement par l’édition publique : leurs bibliothèques et connexions doivent être migrées explicitement.
