# Identité Nino

- Fond sombre #111513 ; accent menthe #7AC7A3 ; papier jaune chaud et ivoire.
- Personnage vectoriel original : crête double, yeux sombres, petite bouche, bras et pieds. Préserver la silhouette dans chaque média.
- Typographie native arrondie pour les titres dans les rendus macOS ; typographie GitHub native dans le README.
- Visuels : scène Mac, post-it tactiles et mouvements du vrai composant SwiftUI. Aucun faux écran de connexion ou compteur inventé.
- Motion : pas articulés, anticipation courte, rebond léger, pauses expressives. Boucles fluides facultatives ; réduire les animations doit arrêter la promenade.
- README : une proposition claire, un téléchargement, trois étapes d’installation, puis capacités et limites.
